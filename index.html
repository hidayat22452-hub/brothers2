Instal Aplikasi di Layar Utama HP

Jadikan aplikasi ini seperti aplikasi Native di Android / iPhone tanpa perlu Play Store/App Store.

Panduan Android (Google Chrome)
  1. Buka halaman web ini di browser Chrome.
  2. Ketuk titik tiga (⋮) di sudut kanan atas.
  3. Pilih menu "Tambahkan ke Layar Utama" atau "Install aplikasi".
  4. Selesai! Ikon TSS Report akan muncul di daftar aplikasi HP Anda.
Panduan iPhone / iPad (Safari)
  1. Buka halaman web ini menggunakan browser Safari.
  2. Ketuk tombol Bagikan (Share icon / kotak panah ke atas) di bagian bawah layar.
  3. Gulir ke bawah dan ketuk "Add to Home Screen" (Tambahkan ke Layar Utama).
  4. Ketuk "Add" di pojok kanan atas.
